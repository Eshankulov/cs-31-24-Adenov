# Практическая работа № 2 — Операционные системы — Вариант B

## Цель
Написать Bash-отчёт по журналам и посмотреть системные вызовы программ.

## Файлы
- `report.sh` — считает сообщения ERROR/WARN по модулю, сортирует по убыванию и поддерживает `--top N`.
- `hello.py` — выводит размер указанного файла в байтах.
- `data/example.log` — небольшой тестовый журнал.

## Запуск
```bash
chmod +x report.sh hello.py
./report.sh data ERROR
./report.sh data WARN --top 1
python3 hello.py data/example.log
```

## Системные вызовы
На Ubuntu с установленным `strace` выполните:
```bash
strace -f -o trace.txt python3 hello.py data/example.log
strace -c cat data/example.log
strace -c python3 hello.py data/example.log
```
Откройте `trace.txt` и посчитайте общее число вызовов по итоговой статистике `strace -c`; отдельно отметьте операции чтения самого файла (например, `openat`, `read`, `close`). Точные количества зависят от версии Python, библиотек и ОС, поэтому их нужно записать по фактическому выводу, а не угадывать. Python обычно вызывает больше системных вызовов, потому что загружает интерпретатор, библиотеки и инициализирует среду; `cat` выполняет более простую задачу.

## Вывод
Системные вызовы дают программе контролируемый доступ к файлам и другим ресурсам ядра. Bash-скрипт проверяет аргументы, каталог и сортирует агрегированные данные.
