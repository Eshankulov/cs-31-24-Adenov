# Практическая работа № 3 — Операционные системы — Вариант B

## Цель
Изучить процессы Linux: дерево процессов, fork/exec/wait, зомби и сироты, а также copy-on-write.

## 1. Дерево текущего пользователя без ps
```bash
python3 ptree.py
```
Скрипт читает `/proc`, фильтрует процессы по UID и показывает PID, PPID, состояние и RSS.

## 2. fork + exec + wait
```bash
python3 runner.py --count 3 -- /bin/sleep 1
```
Создаются три дочерних процесса. Родитель ждёт их завершения и печатает PID, код возврата и время от создания до сбора статуса.

## 3. Зомби и сирота
В одном терминале:
```bash
python3 zombie.py
```
Пока родитель ждёт 15 секунд, в другом выполните `ps -o pid,ppid,stat,cmd -p PID_РЕБЁНКА` и найдите состояние `Z`. После `waitpid` запись исчезнет.

Для сироты:
```bash
python3 orphan.py
```
Родитель завершается первым; ребёнок выводит свой новый PPID. В зависимости от среды WSL/Ubuntu усыновителем обычно становится PID 1 (init/systemd), но это нужно подтвердить фактическим выводом.

## 4. Copy-on-write
```bash
python3 cow_demo.py
```
Скрипт создаёт большой список, выполняет fork и выводит VmRSS ребёнка до и после изменения части списка. Изменение страниц может увеличить RSS ребёнка; точные числа зависят от ядра, памяти и среды. Внесите фактический вывод в отчёт.

## Вывод
`fork` создаёт дочерний процесс с логически унаследованной памятью; copy-on-write позволяет не копировать все страницы немедленно. `exec` заменяет программу процесса, а `wait`/ `waitpid` собирает статус завершения и устраняет зомби.
