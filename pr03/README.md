# Практическая работа № 3 — Операционные системы — Вариант B

## Цель
Изучить дерево процессов Linux и жизненный цикл процесса: создание, замена программы через exec и ожидание завершения через wait.

## Запуск
```bash
python3 proc_tree.py
python3 process_demo.py
ps -eo pid,ppid,stat,cmd --forest | head -40
```

## Что проверяется
- `proc_tree.py` читает `/proc/*/stat`, строит связь PID/PPID и выводит дерево с состояниями.
- `process_demo.py` создаёт ребёнка через `fork()`, заменяет его программу через `exec`, а родитель получает статус через `waitpid()`.
- `ps` показывает процессы, их родителей и состояния.

## Вывод
Процесс имеет собственный PID и состояние; PPID указывает родителя. `fork` создаёт дочерний процесс, `exec` заменяет выполняемую программу, а `waitpid` позволяет родителю собрать статус завершения и не оставлять зомби.
