# Практическая работа № 7 — Операционные системы — Вариант B

## Цель
Сделать клиент–сервер на именованных каналах FIFO: клиент отправляет арифметическое выражение, сервер вычисляет его и отвечает через второй FIFO. Сервер обслуживает запросы по очереди.

## Запуск
В терминале 1:
```bash
python3 server.py
```
В терминале 2 (можно запускать команды по очереди из нескольких терминалов):
```bash
python3 client.py "2 * (3 + 4)"
python3 client.py "100 / 4"
python3 client.py "10 ** 2"
```

## Реализация и безопасность
- Общий FIFO запросов: `/tmp/os_pr07/requests.fifo`.
- Для каждого клиента создаётся отдельный FIFO ответа с уникальным идентификатором.
- Сервер обрабатывает выражения через ограниченный AST-интерпретатор; произвольный Python-код и вызовы функций не разрешены.
- Клиент удаляет свой FIFO ответа в блоке `finally`.

## Вывод
FIFO позволяет передавать данные между независимыми процессами через файловый интерфейс. Открытие FIFO на чтение/запись блокируется до появления второй стороны; сервер обрабатывает запросы последовательно.
