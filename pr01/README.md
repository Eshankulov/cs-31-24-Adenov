# Практическая работа № 1 — Операционные системы — Вариант B

## Цель
Настроить пользователей и группы Linux, права общего каталога и пользовательскую оболочку Bash.

## Файлы
- `setup.sh` — создаёт группу `developers`, пользователя `student2` (если его ещё нет) и каталог `/srv/shared` с правами группы.
- Остальные шаги выполняются вручную, чтобы можно было показать и объяснить результат преподавателю.

## Запуск
В Ubuntu 22.04+ или WSL Ubuntu из каталога репозитория:

```bash
chmod +x setup.sh
./setup.sh
```

Скрипт использует `sudo` и может запросить пароль текущего пользователя. Если пользователь `student2` уже существует, скрипт не создаёт его повторно.

## Проверка прав доступа

```bash
id student2
getent group developers
ls -ld /srv/shared
sudo -u student2 touch /srv/shared/student2-test.txt
ls -l /srv/shared/student2-test.txt
```

Каталог должен принадлежать `root:developers` и иметь режим `2775` (обычно отображается как `drwxrwsr-x`). Бит setgid обеспечивает наследование группы `developers` новыми файлами и подкаталогами. Участники группы могут создавать и удалять файлы в каталоге; остальные могут просматривать содержимое и читать доступные им файлы, но не создавать и не удалять их.

Попытка удалить файл от основного пользователя, который не входит в `developers`, должна завершиться отказом в доступе. Удаление файла определяется правами на каталог, а не только правами самого файла.

## Вопросы

### Чем отличаются `su` и `sudo`?
- `su` переключает пользователя (по умолчанию — на root) и обычно открывает новую оболочку.
- `sudo` запускает указанную команду с правами другого пользователя, обычно root, согласно настройкам sudoers.

### Почему вход root обычно заблокирован в Ubuntu?
Ubuntu обычно использует `sudo` для административных команд, чтобы не работать постоянно с правами суперпользователя и уменьшить риск случайных или вредоносных изменений. Учётная запись root существует, но пароль для прямого входа обычно не задан.

## Настройка ~/.bashrc

Добавьте в конец файла:

```bash
alias ll='ls -lah'
alias c='clear'
export MY_PROJECT="UbuntuLab"
```

Загрузите изменения и проверьте:

```bash
source ~/.bashrc
ll
c
printf '%s\n' "$MY_PROJECT"
```

Чтобы проверить новую сессию, откройте новый терминал и выполните `type ll`, `type c` и `echo "$MY_PROJECT"`.
