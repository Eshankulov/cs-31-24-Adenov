# Практическая работа № 6 — Операционные системы — Вариант B

## Цель
Реализовать кольцевой буфер «производитель–потребитель» ёмкостью 5 без `queue.Queue`, используя два семафора и мьютекс либо мьютекс с условной переменной. Также реализован барьер на 4 потока для трёх фаз.

## Запуск
```bash
python3 sync_demo.py --mode both
python3 sync_demo.py --mode barrier
```

## Проверки
- 3 производителя выпускают по 1000 элементов; 2 потребителя получают их.
- Программа проверяет, что все 3000 элементов уникальны и потреблены ровно один раз.
- Максимальный размер буфера не превышает 5.
- `ConditionRing` использует `while` вокруг `wait()`, чтобы после пробуждения повторно проверить условие.
- Барьер не позволяет потоку перейти к следующей фазе, пока остальные не достигли той же точки.

## Потерянное пробуждение
Замена `while` на `if` небезопасна: после пробуждения поток может обнаружить, что условие уже снова ложно, либо получить spurious wakeup, и продолжить при пустом/полном буфере. Поэтому условие ожидания проверяется циклом под тем же условным мьютексом.

## Вывод
Семафоры учитывают число свободных и занятых ячеек; мьютекс защищает индексы и содержимое. Условная переменная сообщает об изменении состояния, но не заменяет проверку условия.
