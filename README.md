## Файлы репозитория

- `data/tips.csv` — исходный датасет.
- `notebook.ipynb` — ранее существовавший notebook, сохранён отдельно.
- `ПРАКТИКА 1.ipynb` — первичный анализ данных.
- `ПРАКТИКА 2.ipynb` — разведочный анализ; искусственные пропуски и выброс добавлены в отдельную копию данных и явно отмечены в notebook.
- `ПРАКТИКА 3` — существующая работа, оставлена без изменений.
- `ПРАКТИКА 4.ipynb` — линейная регрессия и сравнение моделей.
- `ПРАКТИКА 5.ipynb` — классификация; бинарная метка и стоимость ошибок заданы как учебные допущения, порог подбирается на validation, итоговые метрики считаются на test.
- `ПРАКТИКА 7.ipynb` — дерево решений, случайный лес, настройка параметров и анализ важности признаков.
- `практика 5 Операционные система ` — практическая работа по планированию процессов ОС.
- `практика 6` — существующая работа, оставлена без изменений.

## Запуск

Откройте нужный notebook в Jupyter или загрузите его в Google Colab. Для запуска из Colab ноутбуки могут прочитать `data/tips.csv` из репозитория GitHub, если файл отсутствует в рабочем каталоге.

После изменений сохранённые результаты выполнения очищены, поэтому запустите **Runtime → Run all** (в русской локализации — «Среда выполнения → Выполнить все») и проверьте, что все ячейки завершаются без ошибок.

## Важные допущения

В репозитории не найден отдельный исходный датасет с заранее внесёнными дефектами для практики № 2, поэтому дефекты создаются только в копии исходных данных для демонстрации методов очистки. Для практики № 5 по классификации не было предоставлено отдельной целевой метки и официальной цены ошибок; это явно обозначено в notebook и при необходимости должно быть заменено условиями преподавателя.
